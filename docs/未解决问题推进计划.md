1. **安全止损**：先处理 S01，再处理 S02–S04。此阶段未验收前，不把真实客户明细或正式密钥用于团队共享演示。

4. **数据治理与体验**：完成 D01–D06，重点确保口径、权限、版本和分页；随后做一次全量回归。
